# Дерево агентов для OpenCode Desktop

Откройте **боковую панель → «+» → «Агенты»**, чтобы увидеть, кто кого запустил, какое поручение получил каждый субагент и что он делает сейчас. Нажатие на карточку открывает переписку поверх основного чата. Плагин работает во всех проектах; проверен в **OpenCode Desktop 2.3.2**.

## Промпт для установки

Скопируйте этот текст в OpenCode:

```text
Установи мне глобально плагин «Дерево агентов» для OpenCode Desktop из
https://github.com/troyan-dy/opencode-desktop-agent-tree (релиз v1.0.0).

Скачай готовый gui-experimental.cjs из этого релиза в папку
local-themes/agent-tree внутри моего глобального каталога конфигурации OpenCode.
Обычно это ~/.config/opencode; если задан XDG_CONFIG_HOME, используй
его подкаталог opencode. Проверь SHA-256 файла по SHA256SUMS из того же релиза.

Добавь "./local-themes/agent-tree" один раз в массив plugins существующего
глобального opencode.jsonc или opencode.json. Сохрани остальные настройки
и комментарии; если файла нет, создай opencode.jsonc. Если эта версия уже
установлена и подключена, не дублируй её. Проверь, что OpenCode видит
активный GUI-плагин agent-tree, и подскажи, где открыть вкладку «Агенты».
```

### Установка вручную

1. Из [релиза v1.0.0](https://github.com/troyan-dy/opencode-desktop-agent-tree/releases/tag/v1.0.0) скачайте **`gui-experimental.cjs`** и положите его в `~/.config/opencode/local-themes/agent-tree/`. На Windows `~` — папка пользователя. Если задан `XDG_CONFIG_HOME`, глобальный каталог — `$XDG_CONFIG_HOME/opencode`. Сборка и установка npm-пакетов не требуются.
2. В глобальном `opencode.jsonc` или `opencode.json` добавьте запись в существующий массив `plugins`:

   ```jsonc
   {
     "plugins": [
       "./local-themes/agent-tree"
     ]
   }
   ```

3. Откройте беседу в Desktop и выберите **«+» → «Агенты»** в боковой панели. В **Настройки → Расширения → Плагины** расширение отображается как `agent-tree`.

Для обновления замените файл сборкой из нового релиза. Для удаления уберите запись из `plugins`.

## Что показывает панель

- **Карта беседы.** В корне — основной агент. Линии связывают субагентов с родителями; в каждой карточке видны поручение, роль и статус. Завершённые ветви свернуты под родителем: нажмите **«Завершённые · N»**, чтобы раскрыть их.
- **Переписка.** Нажмите карточку мышью или выберите её клавишей Tab и нажмите Enter. Переписка обновляется во время ответа; действия инструментов можно раскрывать. Крестик или Esc закрывает окно, сохраняя черновик, прокрутку и раскрытые ветви основного чата.
- **Размер контекста.** Кольцо внизу показывает число токенов последнего измеренного ответа субагента и процент от лимита его модели. Наведите курсор, чтобы увидеть лимит. Это размер контекста, а не суммарный расход за беседу.

## Разработка

Для сборки и модульных тестов достаточно Node.js 24:

```sh
node --test
node build.cjs
```

Сборка записывается в `gui-experimental.cjs` в корне репозитория. Плагин использует [GUI API OpenCode Desktop](https://opencode.ai/docs/build/plugins/gui).
