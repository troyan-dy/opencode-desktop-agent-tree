# opencode-desktop-agent-tree

**Левая панель → «+» → «Агенты».** В корне карты — основной агент беседы. У каждого субагента своя карточка: название поручения, роль и значок с текстом текущего статуса. Линии показывают, кто кого запустил. Нажмите **«Завершённые · N»** под родителем, чтобы раскрыть историю. Если агент снова работает, его карточка автоматически возвращается в видимую ветвь.

Для локальной установки запустите `node build.cjs`, скопируйте `gui-experimental.cjs` в `~/.config/opencode/local-themes/agent-tree/` и добавьте `"./local-themes/agent-tree"` в `plugins` глобального `~/.config/opencode/opencode.jsonc`. Работает во всех проектах в OpenCode Desktop 2.3.2. Для удаления достаточно убрать эту запись.

Проверка: `node --test`.
