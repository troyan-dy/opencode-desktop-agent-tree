# «Агенты» в левой панели OpenCode Desktop

В списке «Quota», «Обзор», «Браузер», «Терминал», «Открыть файл» появляется пункт **«Агенты»**. Он открывает вкладку левой панели для текущей беседы. Повторный выбор открывает ту же вкладку.

В корне дерева — основной агент беседы. Под каждым агентом — запущенные им агенты, в том числе завершившиеся. В строке видны имя агента, короткое название поручения и текущее состояние. Если дочерних агентов нет, виден только основной агент с пояснением «Пока нет дочерних агентов».

Панель читает отношения и состояния из данных OpenCode и обновляет их, пока открыта. Она различает работу инструмента, написание ответа, успешное завершение, остановку и ошибку, когда для этого есть данные. Бездействие само по себе не означает успешного завершения. Если агент получает новое поручение, обновляется его строка. При смене беседы меняется дерево.

**Способ реализации.** Локальный GUI-плагин регистрирует пункт `session.panel` и вкладку через `Panel`. Это та же точка расширения, которую уже использует локальная настройка Quota. Вариант с изменением сборки Desktop не даёт преимуществ для такой вкладки и потребовал бы переносить правку при обновлениях.

**Проверка.** Пункт виден в существующем меню; вкладка открывается в левой панели; вложенный агент находится под правильным родителем; смена статуса сохраняет строку и её место в дереве; данные другой беседы не смешиваются с текущими.
