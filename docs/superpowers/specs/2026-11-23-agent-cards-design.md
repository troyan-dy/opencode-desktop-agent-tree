# Карта карточек для вкладки «Агенты»

Выбран вариант **A** из [сравнения трёх интерактивных макетов](https://github.com/troyan-dy/opencode-desktop-agent-tree/pull/2). Он сохраняет главное: один взгляд показывает поручение, состояние и родителя агента. Вариант B группировал по срочности вместо иерархии, C требовал выбора строки для просмотра подробностей.

Верхняя карточка подписана «Основной агент». Для каждого субагента заголовок — поручение, ниже — роль на русском; неизвестная роль отмечается явной подписью. Полоска на левом краю и значок рядом с текстом статуса передают состояние и без опоры на один только цвет. Линии соединяют детей с их родителями. Счётчик включает только реальных субагентов. Без запусков видно явное пустое состояние.

В каждом узле успешно завершённые ветви по умолчанию находятся в раскрываемой строке «Завершённые · N». Если потомок ещё работает, путь к нему остаётся видимым. Открытая история не схлопывается при обновлении данных. Выбор макета не включает режимы B, C или отдельный фильтр.

Место установки — существующий глобальный GUI-плагин OpenCode Desktop. Проверка: реальные данные сеанса, отрисовка карточек в узкой панели, подписи и значки, раскрытие истории и сценарий без субагентов.
